# KnotHub v0.2.1 — 配方市场 & 下载增强

## 新功能

### 📜 配方市场

- 浏览 KnotLink 官网配方索引，横向卡片展示
- 一键导入：自动下载 `.py`/`.kln` 并复制到 Recipes 目录
- 详情预览：描述、标签、串联节点列表、版本信息
- 支持搜索过滤，已导入/未导入状态标识

### ⬇️ MultiDownload 多线程下载

- 设置页可选择启用 MultiDownload（aria2 多线程引擎）
- 自动 fallback：MultiDownload 不可用时降级为 reqwest 单线程下载
- 镜像 fallback：下载失败自动切换备用镜像源
- NSIS 环境检测：安装包自动检查 aria2 可用性

## 修复

### 🔒 插件安装安全性

- **运行中安装不再静默失败**：install 时先停止同名插件进程，再覆盖文件
- `QFile::copy` 返回值检查，复制失败立即报错（之前静默跳过）
- 安装后自动重启之前运行中或配置了自启的插件
- 先清空旧目录再复制，避免残留旧文件导致不一致

## 改进

- `KnotHubCore.exe` 嵌入 VERSIONINFO 资源（版本/公司/产品/版权），右键属性可查看
- 版本号统一升至 0.2.1.0

## 安装

**KnotHub-0.2.1.0-Setup.exe**，用户级安装，无需管理员权限。
